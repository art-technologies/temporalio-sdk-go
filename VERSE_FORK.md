# Verse compatibility fork

Based on upstream Go SDK v1.49.0. The only runtime change preserves implicit child workflow IDs generated by the March 2024 Verse fork (3bf91fa928bc): OriginalRunID, falling back to WorkflowExecution.RunID. Explicit IDs are unchanged.

Upstream changes the ID seed at reset boundaries; existing Verse reset histories therefore fail replay without this patch. Both the pre-serialization path and the bindings fallback must retain this behavior. Do not remove it without replaying and migrating affected histories. New executions intentionally retain the same behavior.

The replay fixtures were produced by a dedicated maintenance workflow with public string inputs, a retry, a timer, a signal, and a cross-namespace child. They contain no business workflow payloads.

Upgrade by branching from an upstream release, porting this change, running both fixtures and representative application replay, then pinning applications to an immutable fork revision. Never overwrite existing release tags.
